# TrussModel_DRCB
Opensees models and postprocessing routines created to validate the nonlinear hysteretic truss model for diagonally reinforced coupling beams.
Each model has its own folder, within each folder, there is a subfolder for the following: Moment Springs, Shear Springs, Truss Model.
A folder for the Santhakumar coupled wall test is also included.

The main file for each model is run.tcl

The Etabs model described in the Application section is also included.
